# Noema Maritime Website

NOEMA GROUP — Maritime Freight Solutions for Dry Bulk Cargo.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Google Fonts (Playfair Display, DM Sans, Courier Prime)

## Pages
- `/` — Home
- `/about` — About
- `/services` — Services
- `/dry-bulk` — Dry Bulk Transport
- `/inquiry` — Cargo Inquiry
- `/vessel-capacity` — Vessel Capacity
- `/market-intelligence` — Market Intelligence
- `/contact` — Contact

## Deploy
Connect this repository to Vercel. It auto-detects Next.js.
No configuration needed — just import and deploy.
